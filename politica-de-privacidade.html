Política de Privacidade

Aplicativo: Cortando · Última atualização: 23 de novembro de 2026

1. O que é o Cortando

O Cortando é um aplicativo de uso pessoal que roda no computador do criador do canal CortEgames. Ele gera cortes de vídeos e, com autorização do dono do canal, publica esses cortes no YouTube e consulta as métricas dos vídeos publicados.

2. Dados acessados pelo Google/YouTube

Ao conectar uma conta do YouTube, o Cortando solicita as permissões abaixo, usadas somente para:

  • youtube.upload: enviar os cortes gerados pelo próprio usuário para o canal dele;
  • youtube: definir título, descrição, capa, visibilidade e data de publicação desses vídeos;
  • yt-analytics.readonly: ler métricas dos vídeos do próprio canal (visualizações, tempo assistido, retenção, inscritos ganhos) para mostrar ao usuário quais cortes tiveram melhor desempenho.

3. Onde os dados ficam

Todos os dados ficam somente no computador do usuário: o token de acesso do Google, os vídeos, as transcrições e as métricas. O Cortando não tem servidor próprio, não envia esses dados para terceiros e não os vende, aluga ou compartilha. A única comunicação externa é com as próprias APIs do Google e do YouTube, para executar as ações pedidas pelo usuário.

4. Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O Cortando também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

5. Como revogar o acesso e apagar os dados

  • No app: aba Contas → Desconectar, que apaga o token salvo no computador.
  • No Google: myaccount.google.com/permissions, removendo o acesso do Cortando.
  • Os demais dados podem ser apagados excluindo a pasta do aplicativo no computador.
