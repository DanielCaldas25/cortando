Política de Privacidade

Aplicativo: Cortando (canal CortEgames) · Última atualização: 24 de novembro de 2026

Este aplicativo usa os Serviços de API do YouTube

1. O que é o Cortando

O Cortando é um aplicativo de uso pessoal do criador do canal CortEgames. Ele gera cortes dos vídeos e, com autorização do dono do canal, usa os Serviços de API do YouTube para publicar e agendar esses cortes no próprio canal e consultar as métricas dos vídeos publicados. Ele não é oferecido a outras pessoas.

Ao usar o Cortando você concorda com os Termos de Serviço do YouTube. Os dados tratados pelo Google seguem a Política de Privacidade do Google (http://www.google.com/policies/privacy).

2. Dados acessados no Google/YouTube

Ao conectar a conta do YouTube, o Cortando pede as permissões abaixo, usadas somente para:

  • youtube.upload: enviar os cortes gerados pelo próprio usuário para o canal dele;
  • youtube: definir título, descrição, capa, visibilidade e data de publicação desses vídeos e ler os dados do próprio canal;
  • yt-analytics.readonly: ler métricas dos vídeos do próprio canal (visualizações, tempo assistido, retenção, inscritos ganhos) para mostrar quais cortes tiveram melhor desempenho.

Não acessamos dados de outros canais ou usuários, não usamos cookies de rastreamento e não exibimos anúncios.

3. Onde os dados ficam

  • No computador do usuário: vídeos, transcrições, métricas e o token de acesso do Google.
  • No projeto privado do Google Apps Script do próprio usuário (conta Google dele): uma cópia do token de atualização, para publicar os vídeos agendados mesmo com o computador desligado; e, temporariamente, os vídeos a publicar no Google Drive do próprio usuário, apagados depois da publicação.

Nenhum dado é vendido, alugado ou compartilhado com terceiros. A comunicação externa é apenas com as APIs do Google e do YouTube, para executar as ações pedidas pelo usuário.

4. Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Como revogar o acesso e apagar os dados

  • No Google: página de configurações de segurança do Google (myaccount.google.com/permissions), removendo o acesso do Cortando.
  • No app: Configurações → Contas → Desconectar, que apaga o token salvo.
  • Os dados guardados são apagados em até 7 dias depois da revogação ou de um pedido pelo e-mail abaixo; os dados obtidos da API do YouTube não são mantidos por mais de 30 dias sem atualização.

Privacy Policy (English)

App: Cortando (CortEgames channel) · Last updated: November 24, 2026

Cortando is a personal tool used only by the owner of the CortEgames channel. It uses YouTube API Services to upload and schedule the owner's own short videos on the owner's own channel and to read that channel's statistics and analytics. By using Cortando you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy (http://www.google.com/policies/privacy).

Data accessed: with the scopes youtube.upload, youtube and yt-analytics.readonly we upload the owner's videos, set their title, description, thumbnail, visibility and publish time, and read the owner's own channel metrics. No data from other users or channels is accessed. No tracking cookies, no ads.

Storage: on the owner's computer and in the owner's private Google Apps Script project (refresh token) and Google Drive (videos waiting to be published, deleted after publishing). Nothing is sold or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking and deletion: revoke access at any time via the Google security settings page or in the app (Settings → Accounts → Disconnect). Stored data is deleted within 7 days of revocation or of a request to the email below; YouTube API data is not kept for more than 30 days without being refreshed.
