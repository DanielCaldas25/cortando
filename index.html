Cortando

Ferramenta pessoal de edição e publicação de cortes de vídeos do canal CortEgames · Personal tool for the CortEgames channel.

Built with YouTube API Services · canal CortEgames no YouTube

O Cortando é um aplicativo do próprio criador. Ele analisa vídeos e lives de jogos, sugere os melhores trechos, gera cortes verticais com legenda e, com autorização do dono do canal, usa os Serviços de API do YouTube para publicar e agendar esses cortes no canal dele e ler as métricas de desempenho dos vídeos publicados.

Cortando is the creator's own tool: it edits short vertical highlight clips and, with the channel owner's authorization, uses YouTube API Services to upload and schedule them on the owner's channel and read that channel's analytics.
